# LP02 / M02 — Manage containers in Azure Container Apps

**Lab:** [02-aca-manage-containers.md](https://github.com/MicrosoftLearning/mslearn-azure-ai/blob/main/instructions/azure-container-apps/02-aca-manage-containers.md)

## Learning objectives (from the deck)
- Update container images and manage revisions safely
- Perform app lifecycle operations and diagnose failing revisions
- Monitor logs and troubleshoot revision/runtime issues
- Configure health probes and troubleshoot probe failures
- Optimize container resources (CPU/memory) for cost and performance
